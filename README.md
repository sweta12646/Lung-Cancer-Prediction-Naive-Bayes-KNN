# 🫁 Lung Cancer Prediction Using Gaussian Naive Bayes and K-Nearest Neighbors (KNN)

## 📌 Project Overview

This project applies machine learning classification techniques to a lung cancer survey dataset to predict the recorded lung cancer status (`YES` or `NO`) based on demographic information and reported symptoms or risk-related factors.

Two classification algorithms are implemented and compared:

- **Gaussian Naive Bayes**
- **K-Nearest Neighbors (KNN)**

The project demonstrates data preprocessing, exploratory data analysis, model training, hyperparameter tuning, and performance evaluation using Python.

## 🎯 Project Objectives

- Analyze the lung cancer survey dataset.
- Clean and preprocess the data.
- Convert categorical variables into machine-readable formats.
- Split the dataset into training and testing sets.
- Build classification models using Gaussian Naive Bayes and KNN.
- Tune the KNN model by testing different values of K.
- Evaluate and compare model performance using classification metrics.
- Identify the strengths and limitations of each algorithm.

## 📂 Dataset Description

**Dataset:** `survey lung cancer.csv`

The dataset contains survey records with demographic information, symptoms, and other reported factors associated with lung cancer status.

### Features used

- Gender
- Age
- Smoking
- Yellow Fingers
- Anxiety
- Peer Pressure
- Chronic Disease
- Fatigue
- Allergy
- Wheezing
- Alcohol Consuming
- Coughing
- Shortness of Breath
- Swallowing Difficulty
- Chest Pain

**Target variable:** `LUNG_CANCER`

- `YES` — recorded lung cancer status is positive.
- `NO` — recorded lung cancer status is negative.

The dataset's labels represent survey records and should not be interpreted as a clinical diagnosis.

### 5. Model Building

**Gaussian Naive Bayes:** Uses Bayes' theorem and assumes that numerical features follow a Gaussian distribution within each class.

**K-Nearest Neighbors (KNN):** Classifies a record based on the classes of its nearest neighbors. Different values of K are tested to identify a suitable setting.

Evaluate both models using:

- Classification report

KNN performance is also examined across different K values, with cross-validation used where implemented.
